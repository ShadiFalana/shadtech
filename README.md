# SHADTECH

منصة تقنية متكاملة للشركات الصغيرة والمتوسطة: الدعم الفني، إدارة العلاقات، التذاكر (ITSM)،
المتجر، المبيعات والفوترة، المالية، المخزون، الموارد البشرية، الهوية والصلاحيات، الأمن،
الذكاء الاصطناعي، وذكاء الأعمال — ضمن نواة واحدة مترابطة.

> **الحالة:** الخطوة 4 — الصلاحيات وتعدد المؤسسات. حسابات حقيقية، جلسات قابلة للإبطال، وتحديث تلقائي للرمز
> جاهزة. الخطوة 5 (الشركات والفروع) تبدأ بعد الاعتماد.

## المتطلبات

- Node.js 22 أو أحدث (تم التحقق على Node 24)
- npm 10 أو أحدث

## التشغيل السريع

```bash
npm install
```

ثم في ثلاث طرفيات منفصلة:

```bash
npm run dev:db    # قاعدة بيانات PostgreSQL محلية على 127.0.0.1:5432
npm run dev:api   # http://localhost:3001/api/v1
npm run dev:web   # http://localhost:5173
```

عند أول تشغيل فقط، طبّق الهجرات وأدخل البيانات الأولية:

```bash
npm run db:migrate
npm run db:seed
```

- فحص صحة الخدمة والقاعدة: <http://localhost:3001/api/v1/health>
- الواجهة العربية: <http://localhost:5173> — تسجيل دخول حقيقي ثم لوحة تحكم.
- وضعان داكن وفاتح مع زر تبديل يحفظ اختيارك في المتصفح.
- بيانات التطوير تُخزَّن في `backend/.pgdata` (مستثناة من Git) ولا تحتاج Docker.

> **الدخول التطويري:** `admin@shadtech.local` / `ChangeMe123!` (ينشئه `db:seed`).
> غيّره قبل أي نشر حقيقي. على قاعدة فارغة تعرض الواجهة نموذج إنشاء المسؤول الأول.

> ضع `JWT_SECRET` في `backend/.env` (انظر `backend/.env.example`)؛ إلزامي في الإنتاج.
> يُولَّد بـ: `node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"`

## الأوامر

| الأمر                | الوصف                                 |
| -------------------- | ------------------------------------- |
| `npm run dev:db`     | تشغيل PostgreSQL المحلي للتطوير       |
| `npm run dev:api`    | تشغيل API في وضع التطوير              |
| `npm run dev:web`    | تشغيل واجهة الويب                     |
| `npm run db:migrate` | إنشاء/تطبيق هجرة جديدة أثناء التطوير  |
| `npm run db:deploy`  | تطبيق الهجرات الموجودة (بيئات منشورة) |
| `npm run db:seed`    | إدخال البيانات الأولية                |
| `npm run db:studio`  | فتح Prisma Studio لفحص البيانات       |
| `npm run db:reset`   | إعادة بناء قاعدة التطوير من الصفر     |
| `npm run build`      | بناء الخلفية والواجهة للإنتاج         |
| `npm run typecheck`  | فحص الأنواع في كل الحزم               |
| `npm run format`     | تنسيق الملفات عبر Prettier            |

## البنية

```
SHADTECH/
├── apps/
│   └── web/                 # React + Vite (عربي RTL)
│       └── src/
│           ├── pages/       # شاشة الدخول/التهيئة ولوحة التحكم
│           ├── components/  # الهوية البصرية والأيقونات
│           └── lib/         # عميل API، سياق المصادقة، فحص الصحة
├── backend/                 # NestJS API
│   ├── prisma/
│   │   ├── schema.prisma    # المخطط والهجرات
│   │   └── migrations/      # هجرات قاعدة البيانات
│   ├── scripts/             # تشغيل قاعدة التطوير المحلية
│   └── src/
│       ├── auth/            # تسجيل/دخول/خروج/تحديث الجلسة + JWT guard
│       ├── prisma/          # PrismaService والاتصال
│       ├── health/          # GET /api/v1/health (مع فحص القاعدة)
│       ├── app.module.ts
│       └── main.ts
├── docs/                    # خارطة الطريق وتوثيق الخطوات
├── packages/                # حزم مشتركة (لاحقًا)
├── package.json             # npm workspaces
└── tsconfig.base.json
```

## المبادئ

1. **بناء متدرج:** كل خطوة تُنجز وتُختبر وتُعتمد قبل التالية.
2. **نواة موثوقة أولًا:** الأمان والعزل بين المؤسسات قبل الوحدات التجارية.
3. **عربي أولًا:** واجهة RTL أصلية، مع قابلية التوسع دوليًا لاحقًا.
4. **توثيق واختبارات:** جزء من كل خطوة، لا مرحلة منفصلة في النهاية.

راجع [docs/roadmap.md](docs/roadmap.md) لخطة الخطوات والعناصر المنجزة.
