# خارطة طريق SHADTECH

كل خطوة تُسلَّم كوحدة قابلة للتشغيل والفحص، ثم تتوقف المراجعة حتى الاعتماد.

| #   | الخطوة                   | النطاق                                                   | الحالة                       |
| --- | ------------------------ | -------------------------------------------------------- | ---------------------------- |
| 1   | الهيكل الأساسي           | monorepo، API الصحة، واجهة عربية RTL، بناء وفحص أنواع    | ✅ مكتملة ومعتمدة            |
| 2   | قاعدة البيانات           | PostgreSQL، Prisma، المخطط الأساسي، الهجرات، اتصال الصحة | ✅ مكتملة ومعتمدة            |
| 3   | المصادقة                 | تسجيل، دخول، خروج، تحديث الجلسة، كلمات مرور آمنة         | ✅ مكتملة ومعتمدة            |
| 4   | الصلاحيات وتعدد المؤسسات | أدوار، أذونات، `tenant_id`، عزل صارم للبيانات            | ✅ مكتملة ومعتمدة            |
| 5   | الشركات والفروع          | إدارة الكيانات والفروع والهيكل التنظيمي                  | ✅ مكتملة ومعتمدة            |
| 6   | المستخدمون               | إدارة الحسابات، الأدوار، إعادة تعيين كلمة المرور         | ✅ مكتملة ومعتمدة            |
| 7   | العملاء                  | سجل العملاء، جهات الاتصال، البحث والتصفية                | ✅ مكتملة ومعتمدة            |
| 8   | سجل التدقيق              | تسجيل الأحداث الحساسة وعرضها                             | ✅ مكتملة ومعتمدة            |
| 9   | واجهة الاستخدام          | لوحة تحكم وشاشات الوحدات المنجزة                         | ✅ مكتملة — بانتظار الاعتماد |
| 10  | الاختبارات والتوثيق      | اختبارات وحدات وتكامل، توثيق، وتكامل مستمر               | التالية                      |

## معايير الإنجاز لكل خطوة

- فحص الأنواع يمر دون أخطاء.
- البناء الإنتاجي ينجح.
- الوظائف الجديدة مُختبرة يدويًا (أو آليًا عند توفر الاختبارات).
- توثيق مختصر للتشغيل والقرارات.
- إيداع Git واضح.
- توقف للمراجعة والاعتماد قبل الخطوة التالية.
