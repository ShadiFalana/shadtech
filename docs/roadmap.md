# خارطة طريق SHADTECH

كل خطوة تُسلَّم كوحدة قابلة للتشغيل والفحص، ثم تتوقف المراجعة حتى الاعتماد.

| # | الخطوة | النطاق | الحالة |
| --- | --- | --- | --- |
| 1 | الهيكل الأساسي | monorepo، API الصحة، واجهة عربية RTL، بناء وفحص أنواع | قيد الإنجاز |
| 2 | قاعدة البيانات | PostgreSQL، Prisma، المخطط الأساسي، الهجرات، اتصال الصحة | قادمة |
| 3 | المصادقة | تسجيل، دخول، خروج، تحديث الجلسة، كلمات مرور آمنة | قادمة |
| 4 | الصلاحيات وتعدد المؤسسات | أدوار، أذونات، `tenant_id`، عزل صارم للبيانات | قادمة |
| 5 | الشركات والفروع | إدارة الكيانات والفروع والهيكل التنظيمي | قادمة |
| 6 | المستخدمون | إدارة الحسابات، الأدوار، إعادة تعيين كلمة المرور | قادمة |
| 7 | العملاء | سجل العملاء، جهات الاتصال، البحث والتصفية | قادمة |
| 8 | سجل التدقيق | تسجيل الأحداث الحساسة وعرضها | قادمة |
| 9 | واجهة الاستخدام | لوحة تحكم وشاشات الوحدات المنجزة | قادمة |
| 10 | الاختبارات والتوثيق | اختبارات وحدات وتكامل، توثيق، وتكامل مستمر | قادمة |

## معايير الإنجاز لكل خطوة

- فحص الأنواع يمر دون أخطاء.
- البناء الإنتاجي ينجح.
- الوظائف الجديدة مُختبرة يدويًا (أو آليًا عند توفر الاختبارات).
- توثيق مختصر للتشغيل والقرارات.
- إيداع Git واضح.
- توقف للمراجعة والاعتماد قبل الخطوة التالية.
