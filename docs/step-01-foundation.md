# الخطوة 1 — الهيكل الأساسي

## الهدف

تأسيس مستودع نظيف وقابل للتشغيل يحتوي على خلفية API وواجهة ويب عربية، مع أدوات الجودة
الأساسية — دون قاعدة بيانات أو مصادقة أو وحدات تجارية.

## النطاق المنفَّذ

- npm workspaces: `backend` و`apps/web` (ومجلد `packages/*` محجوز للمشترك لاحقًا).
- TypeScript صارم مع إعدادات مشتركة في `tsconfig.base.json`.
- خلفية NestJS:
  - بادئة موحدة `/api/v1`.
  - `GET /api/v1/health` يعيد الحالة والإصدار ومدة التشغيل.
  - تحقق عام عبر `ValidationPipe`.
  - CORS مقيّد بأصل الواجهة.
- واجهة React + Vite:
  - عربية أصلية `dir="rtl"`.
  - شاشة دخول بتصميم مقسوم، تحقق من البريد وكلمة المرور، وإظهار/إخفاء كلمة المرور.
  - لوحة تحكم تأسيسية: شريط جانبي، مؤشرات فارغة، حالة النظام، الخطوات القادمة،
    ووحدات المنصة.
  - **وضع معاينة فقط:** أي بريد صحيح وكلمة مرور من 6 أحرف تفتح اللوحة؛ لا تُرسل بيانات
    ولا توجد مصادقة حقيقية بعد.
  - فحص حي لصحة API عبر بروكسي التطوير، مع تذكّر جلسة المعاينة في `sessionStorage`.
  - لوحة ألوان نيلية موحّدة، ووضعان داكن وفاتح مع زر تبديل يحفظ الاختيار في `localStorage`
    ويتبع تفضيل النظام عند أول زيارة.
- أدوات: Prettier، `.editorconfig`، `.gitignore`، ومتطلبات إصدار Node.

## خارج النطاق (خطوات لاحقة)

- قاعدة البيانات وPrisma.
- المصادقة والجلسات.
- الأدوار والعزل بين المؤسسات.
- أي كيان تجاري (شركات، مستخدمون، عملاء، تذاكر).
- الاختبارات الآلية (تبدأ مع الخطوات الوظيفية وتُستكمل في الخطوة 10).

## التحقق

```bash
npm install
npm run typecheck
npm run build
npm run dev:api
# terminal آخر
npm run dev:web
```

المتوقع:

- `node dist/main.js` يبدأ دون أخطاء.
- `GET /api/v1/health` يعيد `200` مع `status: "ok"`.
- `http://localhost:5173` تعرض شاشة الدخول العربية وتشير إلى «الخدمة متصلة».
- إدخال بريد صحيح وكلمة مرور من 6 أحرف يفتح لوحة التحكم، و«تسجيل الخروج» يعيد لشاشة الدخول.

## قرارات معمارية

| القرار                      | السبب                                            |
| --------------------------- | ------------------------------------------------ |
| Monorepo عبر npm workspaces | بساطة بدون أدوات إضافية، ومناسب لمطور واحد مع AI |
| NestJS                      | بنية وحدات واضحة، حقن تبعيات، تحقق، وقابلية توسع |
| React + Vite                | سرعة تطوير وبناء، ونظام بيئي واسع                |
| عزل الخطوات                 | تقليل المخاطر ومراجعة أسهل لكل تسليم             |
